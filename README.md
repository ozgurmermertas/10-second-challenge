# 10 Second Challenge

An Arduino-based game where the player tries to stop a timer as close to 10 seconds as possible.

## About the Project

The goal of this project is to test the player's timing accuracy using an Arduino and an LCD screen.

The player starts the timer and attempts to stop it when they think exactly 10 seconds have passed.

## Features

* Timer-based gameplay
* LCD screen interface
* Player timing accuracy measurement
* Arduino-based implementation

## Hardware

* Arduino board
* LCD display
* Input buttons
* Connecting wires

## How to Play

1. Start the timer.
2. Try to estimate when 10 seconds have passed.
3. Stop the timer.
4. Check how close your result is to 10 seconds.

## Source Code

The Arduino source code is available in `LCDEKRAN.ino`.
